# Tushar Maru — Videographer & Video Editor Portfolio

Official portfolio website for **Tushar Maru**, a premier Videographer & Video Editor based in Mumbai, India.

## 🎬 Features
- **Cinematic Dark UI**: Custom-crafted obsidian theme with film grain, reel indicators, and glowing typography.
- **Editorial Typography Combination**: Blends **Syne** (bold display), **Playfair Display** (editorial serif italic), and **Plus Jakarta Sans** (interface).
- **YouTube Video Showcase**: High-impact reel cuts with automatic thumbnail generator and modal video player.
- **Photo Showcase Gallery**: Filterable photo gallery with fullscreen lightbox viewer for behind-the-scenes photography.
- **Production Timeline**: Work experience and associate director milestones.
- **Integrated Admin Control Panel**: Live content management at `/#admin`.
- **Cloudinary Image CDN**: Unsigned image upload support directly in the browser.

## 🚀 Tech Stack
- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS + Custom Typography
- **Animation**: Framer Motion
- **Storage**: Cloudinary + LocalStorage / Firebase
- **Deployment**: Vercel

## 🛠️ Local Development
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
